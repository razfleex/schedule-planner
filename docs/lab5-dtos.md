# Лабораторная работа №5. Pydantic DTO

## Назначение

DTO (Data Transfer Object) используются для передачи данных между пользовательским интерфейсом, API и бизнес-логикой приложения.

Для описания и валидации данных используется Pydantic.

## Структура пакета

- `dtos/__init__.py` — инициализация пакета.
- `dtos/requests.py` — модели входящих запросов.
- `dtos/responses.py` — модели ответов.

## Входящие DTO

- TeacherRequest
- GroupRequest
- SubjectRequest
- ClassroomRequest
- LessonRequest

Входящие модели проверяют:

- Положительные значения идентификаторов.
- Непустые текстовые поля.
- Допустимые дни недели.
- Корректность времени начала и окончания занятия.
- Наличие обязательных полей.

## Выходящие DTO

- TeacherResponse
- GroupResponse
- SubjectResponse
- ClassroomResponse
- LessonResponse

Выходящие модели поддерживают преобразование доменных объектов с помощью `ConfigDict(from_attributes=True)`.

LessonResponse содержит вложенные модели преподавателя, группы, дисциплины и аудитории.

## Архитектура

DTO отделены от доменных моделей и бизнес-логики приложения.

Проверка временных конфликтов занятий остаётся в ScheduleService. Доступ к данным осуществляется через существующие репозитории и Unit of Work.

DTO предназначены для дальнейшего использования в маршрутах FastAPI.
